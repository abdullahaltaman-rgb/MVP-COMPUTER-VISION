# حزمة الحافة — أبيض فيجن (صندوق N100 داخل الفرع)

Frigate 0.17 (OpenVINO على iGPU) + mosquitto + **جسر أبيض**:
`Frigate MQTT → محرك قواعد §5 → بوابة الثقة → إطار دليل → طابور offline-first → السحابة`

## التجهيز الميداني

```bash
cd edge
cp .env.example .env      # عبّئ بيانات RTSP للكاميرات الثلاث
# CLOUD_DEVICE_TOKEN: يُطبع مرة واحدة عند بذر السحابة (npm run db:seed في /cloud)
docker compose up -d
```

1. **الكاميرات:** ثلاث كاميرات RTSP (المعالجة، الاستقبال، النفايات) على شبكة الفرع.
2. **المناطق:** إحداثيات المناطق في `frigate/config.yml` قوالب مبدئية — اضبطها من
   محرر مناطق Frigate (`http://localhost:5000`) بعد التركيب وانسخها للملف.
3. **التحقق:** خلال دقيقة يظهر الجهاز «متصل» في `/ops` → صحة الأجهزة.

## الخصائص

- **offline-first:** كل حدث/لقطة يدخل طابور SQLite قبل الرفع؛ عند انقطاع الإنترنت
  تتراكم وتُرفع تلقائيًا عند عودته (تراجع أُسّي حتى ساعة). لا فقدان أدلة.
- **heartbeat كل 60 ثانية:** حالة الصندوق + fps لكل كاميرا + حجم الطابور؛
  السحابة تُنبّه غرفة العمليات عند انقطاع ≥ 5 دقائق.
- **تحديث عن بُعد:** عتبات/نوافذ/جداول البنود و SILENT_MODE تُسحب من
  `/api/edge/config` كل نبضة — تغيير من `/ops` يصل خلال ≤ 60 ثانية دون إعادة نشر.
- **خصوصية:** لا صوت إطلاقًا (`audio.enabled: false` + `-an`)، لا تعرف على وجوه،
  تسجيل محلي 7 أيام فقط.
