# منظومة أبيض للرصد الآلي للامتثال البلدي — العرض الحي

> **نموذج تجريبي — بيانات توضيحية.** منظومة رصد امتثال بالذكاء الاصطناعي لقطاع المغاسل (أمانة منطقة الرياض): كاميرا الهاتف ترصد المخالفات لحظيًا، تُنشئ حالة، وتوقّع الدليل بسلسلة عهدة رقمية `sha256` غير قابلة للتلاعب.

الواجهة عربية بالكامل، اتجاه `rtl`، بأرقام غربية. الخطوط: **Noto Kufi Arabic** للعناوين و**Noto Sans Arabic** للنصوص.

---

## 🎬 دليل العرض (النجمة الشمالية)

قدّم العرض بهذا التسلسل — يعمل من طرفٍ إلى طرف:

1. **الهاتف:** افتح الرابط ← اضغط **«جرّب الرصد الحي الآن»** ← اسمح بالكاميرا الخلفية.
2. وجّه الكاميرا نحو الغرفة ← خلال ثوانٍ تظهر الصناديق والعناوين العربية:
   - كوب/مشروب ← **بند 7/8/1/1** «تناول الأطعمة والمشروبات في مواقع العمل».
   - شخص دون زيّ موحّد ← **بند 3/8/1/1**.
3. عند ثقة ≥ 85% تُنشأ **حالة** ويُوقَّع الدليل، ويظهر توست: «تم توليد حالة وتوقيع الدليل — رقم …» (اضغطه لفتح الحالة).
4. **جهاز ثانٍ:** افتح `/ministry` ← تُحدَّث اللوحة حيًّا (كل 5 ثوانٍ) وتظهر الحالة الجديدة خلال ثوانٍ.
5. افتح الحالة ← **العدّاد التنازلي** لمهلة التصحيح يعمل، و**«التحقق من سلامة الدليل»** أخضر.
6. في `/ops` اضغط **«محاكاة عبث»** ← يتحوّل التحقق إلى الأحمر كاشفًا التلاعب ← **«استعادة»** يُصلحه.
7. في `/owner` ارفع **«لقطة التصحيح»** ← تُغلق الحالة خضراء موثّقة في السلسلة.

> إن رُفض إذن الكاميرا أو تعذّرت: يظهر **معرض المشاهد التسعة** الجاهزة + رفع صورة، فيبقى العرض كاملًا.

## 🗺️ الصفحات

| المسار | الوصف |
|--------|-------|
| `/` | الهبوط: البطل + الإحصاءات + بطاقات اللوحات |
| `/live` | **البطل** — الرصد الحي بالكاميرا (هوية CCTV) |
| `/ministry` | غرفة عمليات الامتثال (عرض فقط، تحديث كل 5 ثوانٍ) |
| `/case/[id]` | تفاصيل الحالة: الدليل، سلسلة العهدة، العدّاد التنازلي، بطاقة الفرع |
| `/owner` | لوحة المالك: التنبيهات ورفع لقطة التصحيح |
| `/ops` | غرفة العمليات: المراجعة البشرية، عتبة الثقة، العبث/الاستعادة، إعادة التعيين |
| `/how` | كيف تعمل (قصة للمستثمرين وغير التقنيين) |
| `/report/monthly` | تقرير A4 قابل للطباعة ببصمة جذر السلسلة |

## ⚙️ التشغيل محليًا (استنساخ جديد → يعمل)

```bash
git clone <REPO_URL> && cd MVP-COMPUTER-VISION
npm install
cp .env.example .env          # DATABASE_URL=file:./dev.db جاهز
npm run db:push               # إنشاء الجداول
npm run db:seed               # زرع 6 فروع، 9 بنود، 6 حالات تاريخية
npm run dev                   # http://localhost:3000
```

> **بدون مفتاح Gemini** يعمل كل شيء عبر محرّك **المحاكاة** تلقائيًا. لتفعيل الذكاء الحقيقي: ضع `GEMINI_API_KEY` في `.env`.

## ☁️ النشر على Vercel + Turso (خطوة بخطوة)

### 1) قاعدة بيانات Turso (libSQL)
```bash
# ثبّت turso وسجّل الدخول
curl -sSfL https://get.tur.so/install.sh | bash
turso auth login

# أنشئ القاعدة واحصل على الرابط والرمز
turso db create abyad-vision
turso db show abyad-vision --url          # → TURSO_DATABASE_URL (libsql://…)
turso db tokens create abyad-vision       # → TURSO_AUTH_TOKEN

# طبّق المخطّط على Turso (يولّد SQL من مخطّط Prisma):
npm run turso:schema | turso db shell abyad-vision

# ازرع البيانات في Turso:
TURSO_DATABASE_URL="libsql://…" TURSO_AUTH_TOKEN="ey…" npx tsx prisma/seed.ts
```

### 2) النشر عبر Vercel CLI
```bash
npm i -g vercel
vercel login
vercel link                 # اربط المشروع

# أضف متغيّرات البيئة (Production):
vercel env add TURSO_DATABASE_URL production
vercel env add TURSO_AUTH_TOKEN  production
vercel env add GEMINI_API_KEY    production     # اختياري (بدونه يعمل بالمحاكاة)
vercel env add CRON_SECRET       production     # أي سلسلة سرّية

vercel --prod               # ← يطبع الرابط الحي في النهاية
```

> **Cron:** ملف `vercel.json` يجدول `/api/cron/reset` كل 6 ساعات (يمسح بيانات الزوّار الأقدم من 6 ساعات ويُبقي الحالات التاريخية). يستخدم Vercel `CRON_SECRET` تلقائيًا في ترويسة الطلب.

## 🧠 محرّك الكشف — `lib/detector.ts`
واجهة واحدة `detect(imageBase64, ctx)`:
1. **GeminiProvider:** `gemini-2.5-flash-lite` (احتياطي `gemini-2.0-flash`) عبر مسار خادم؛ يُقيّم الصورة *كأنها منطقة عمل مغسلة* مقابل الكتالوج المغلق ويُعيد **JSON صارمًا** (`code, status, confidence, bbox, note_ar`) مع تحليل دفاعي.
2. **MockProvider:** بلا مفتاح / عند تجاوز الحدّ / `?mock=1` — نتائج حتمية للمشاهد، وزوج معقول متناوب لإطارات الكاميرا (يضمن ظهور 3/8/1/1 و7/8/1/1).

**البوّابة:** ≥ 0.85 إصدار آلي (توقيع + حالة) · 0.60–0.84 طابور مراجعة · < 0.60 إهمال.

## 🔗 سلسلة العهدة — `lib/chain.ts`
لكل دليل: `hash = sha256(bytes + prevHash)` مرتبطة عالميًا (`chainIndex`, `prevHash`). نقطة النهاية `/api/chain/verify` تُعيد الحساب كاملًا وتُظهر `ok/broken` لكل سجل. تعديل بايت واحد يكسر التحقق فورًا.
