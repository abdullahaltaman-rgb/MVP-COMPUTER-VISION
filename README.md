# أبيض فيجن v1.0 — إنتاج

منظومة رصد امتثال حقيقية لفرع مغسلة واحد في الرياض (3 كاميرات RTSP):
رصد آلي لبنود لائحة المغاسل (§5)، حالات بمهلة تصحيح 48 ساعة، سلسلة عهدة
`sha256(bytes+prevHash)`، تقارير أسبوعية موقّعة، وبوابة معايرة إلزامية قبل الإطلاق.
الواجهة عربية RTL بالكامل بنفس هوية الديمو (Noto Kufi/Sans Arabic، أرقام غربية).

> المرجع: [`docs/SPEC_أبيض_فيجن_v1.md`](docs/SPEC_أبيض_فيجن_v1.md) —
> ملف الـ PRD الأصلي لم يكن في المستودع (رُفع خطأً كاسم فرع)، والمواصفة تُثبّت
> القرارات المعتمدة. نسخة العرض العام السابقة محفوظة على فرع
> `claude/abyad-vision-live-demo-tg3i1j`.

## المكوّنان

| | المسار | التقنية | الدور |
|---|---|---|---|
| **الحافة** | [`/edge`](edge/) | Frigate 0.17 (OpenVINO) + mosquitto + جسر Python 3.11 | داخل الفرع: كشف، قواعد §5، أدلة، طابور offline-first، نبض 60ث |
| **السحابة** | [`/cloud`](cloud/) | Next.js 14 + Prisma + Postgres + S3 + FCM + Gemini | ingest، بوابة الثقة، الحالات، السلسلة، اللوحات PWA، التقارير |

```
كاميرات RTSP ──► Frigate (OpenVINO) ──► MQTT ──► الجسر (قواعد §5 + نافذة تأكيد)
                                                    │  طابور SQLite (offline-first)
                                                    ▼
                          السحابة: تحقق دلالي Gemini ► بوابة الثقة ► حالة/مراجعة
                          سلسلة العهدة (S3 سعودي) · FCM · تقارير موقّعة · لوحات PWA
```

## اللوحات (PWA قابلة للتثبيت — واجهة الطيار المؤقتة)

| المسار | الدور |
|---|---|
| `/operator` | تنبيهاتي، حالات فرعي بعدادات المهل، شاشة الحالة بالدليل، رفع لقطة التصحيح → إعادة كشف → إغلاق تلقائي |
| `/kafeel` | مؤشر الفرع، الحالات (قراءة)، التقارير الموقّعة PDF، التصعيدات بشارة حمراء |
| `/ops` | طابور المراجعة (اعتماد/استبعاد)، تصنيف المعايرة صحيح/خاطئ + الرسم اليومي، صحة الأجهزة (تنبيه انقطاع ≥5د)، العتبات والجداول، مفتاح SILENT_MODE، سجل التدقيق |
| `/ministry` | قراءة فقط ببيانات حقيقية (وصول داخلي) + بصمات التشغيل الموقّعة |

الدخول برمز وصول لكل دور (تُطبع الرموز عند البذر) — تكامل تطبيق المالك الأصلي
موثّق في [`docs/INTEGRATION.md`](docs/INTEGRATION.md) (OpenAPI + حمولات FCM).

## البوابات الإلزامية

- **SILENT_MODE** (يبدأ مفعّلًا): كل الرصدات → المراجعة فقط، صفر إشعارات للعميل.
- **بوابة المعايرة:** لا go-live دون **دقة ≥ 90% على 200+ حدث مصنَّف**
  (تُحسب يوميًا لكل بند وتُعرض في `/ops` مع منحنى الدقة/الإنذار الكاذب).

## تشغيل السحابة

```bash
cd cloud
npm install
cp .env.example .env        # DATABASE_URL (Postgres) إلزامي؛ البقية حسب البيئة
npm run db:push && npm run db:seed   # يطبع رمز الجهاز ورموز دخول الأدوار
npm run dev
```

**التحقق التشغيلي** (يتطلب Postgres):
```bash
DATABASE_URL=... npx tsx scripts/verify-runtime.ts   # 24 فحصًا: سلسلة، بوابة، دورة حياة، عبث، تقارير
```

**النشر: Vercel** (القرار مُسبَّب في المواصفة): كل المجدولات دفعات قصيرة تناسب
Vercel Cron (`cloud/vercel.json`) — صحة 5د، دورة حياة 15د، فحص دلالي 120د +
استطلاع دفعات Gemini 15د، يومي (بصمة تشغيل + مقاييس + إتلاف)، أسبوعي
(الخميس 14:00 UTC = 17:00 الرياض). كشف الانقطاع يُحسب من آخر نبض عند القراءة،
فلا حاجة لخادم مقيم (Fly يُبرر فقط عند إضافة بث فيديو حي — خارج نطاق v1).

اضبط Root Directory في Vercel على `cloud/`، وأضف متغيرات `.env.example`
(Postgres مُدار، S3 متوافق بمنطقة سعودية، `GEMINI_API_KEY`،
`FIREBASE_SERVICE_ACCOUNT_B64`، `SIGNING_PRIVATE_KEY_PEM`، `CRON_SECRET`).

## تشغيل الحافة (داخل الفرع)

```bash
cd edge
cp .env.example .env   # بيانات RTSP + CLOUD_DEVICE_TOKEN من خرج البذر
docker compose up -d   # frigate + mqtt + bridge
```
التفاصيل والضبط الميداني للمناطق: [`edge/README.md`](edge/README.md).

## الخصوصية (منفّذة في الكود)

لا صوت في أي مسار (`-an`) · لا قصاصات وجوه · إتلاف بايتات الأدلة بعد 90 يومًا
(تبقى البصمات والسلسلة قابلة للتحقق) · حذف السجلات بعد سنتين · صور الأدلة خلف
مصادقة · S3 بمنطقة سعودية.

## إعادة استخدام كود الديمو

واجهة المحرك (`detect`)، مكتبة السلسلة (`lib/chain.ts` — نفس الدالة حرفيًا)،
شاشات الحالة (`CaseVerifyPanel`، `Countdown`)، كتالوج البنود، وكل الـ design tokens
(`globals.css`، `tailwind.config.ts`) منقولة من الديمو ومكيّفة للإنتاج.
